# 📊 Excel Practice

A dedicated Data Analytics portfolio repository focused purely on Excel pipeline architecture, data cleaning, and logic gates.

## Workflow & Architecture
Every practice in this repository strictly adheres to the **Real-Life Analyst Loop** and the **3-Tab Architecture**:
1. **Raw_Data:** Unmodified source data (Scraped or provided).
2. **Clean_Data:** Data cleaned natively via Data Engineering principles (handling missing values, text parsing, trimming).
3. **Dashboard_Engine:** Pivot tables, aggregators, and logic gates driving the frontend UI.
4. **Dashboard:** The final interactive UI canvas.

## Project Structure
Each analysis challenge is isolated into its own dedicated folder containing the raw datasets and the final Excel workbook.
